### OpenAPI Specification

- ASP.NET Core generates an OpenAPI document using `AddOpenApi()`.
- The OpenAPI document is available at:
  - `/openapi/v1.json`

### Scalar

- Scalar is configured to display the ASP.NET Core OpenAPI document.
- Available at:
  - `/scalar`

### Swagger UI

- Swagger UI is configured separately using Swashbuckle.
- Available at:
  - `/swagger`

### API Documentation

The project provides two API documentation interfaces:

- **Scalar** — `/scalar`
- **Swagger UI** — `/swagger`

The OpenAPI document generated by ASP.NET Core is available at:

- `/openapi/v1.json`
